# Maju-Telco chat

## Scope and mode

- Primary target: `apps/web/src/routes/index.tsx`
- Related targets: sidebar, icon set, and global Tailwind entry stylesheet
- Mode: Operate

## Audience and task

Maju-Telco customers need to ask concise questions about mobile data packages, compare catalog options, and understand quotas, validity, prices, and terms. Preserve the established Claude-like chat composition and every existing responsive and interaction state while replacing borrowed branding and the large selector-based stylesheet.

## Direction contract

**THESIS:** A crisp network-wayfinding workspace: familiar chat ergonomics with Maju-Telco’s own signal language. It refuses Claude’s warm charcoal, serif, and terracotta identity without disturbing the proven shell.

**OWN-WORLD:** Cool daylight canvas, deep navy navigation rail, porcelain message surfaces, cobalt actions, and cyan signal details. Humanist system sans throughout; compact, legible controls; softly squared surfaces. The authored Maju-Telco mark combines an M-shaped route with a signal node.

**STORY:** Customers immediately recognize Maju-Telco, ask about packages, read an authoritative response, and retain clear access to chats and controls. Color identifies navigation, action, focus, success, and error rather than decorating neutral chrome.

**FIRST VIEWPORT:** The existing 280px side rail remains on desktop, with the centered greeting and anchored composer occupying the main canvas. Mobile retains its top bar and drawer. Brand mark, empty state, message stream, loading, error, and composer states remain in their current positions and scale.

**FORM:** Coverage-map wayfinding, third in the grounded direction list; seed `2757ce56`. The signature move is a three-node signal pulse used only while the assistant is thinking, echoing the brand mark without changing interaction structure.

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Constraints

- Tailwind utility classes replace the large custom selector stylesheet.
- Preserve chat streaming, responsive sidebar, recent conversation, composer, loading, error, keyboard, and focus behavior.
- Do not use Claude branding, Claude’s icon, or its warm brown/orange palette.
- Do not invent product capabilities or package claims.
